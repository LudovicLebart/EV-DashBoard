# EV-DashBoard

Télémétrie de véhicules électriques, santé de la batterie et prédiction d'autonomie hivernale. Cible primaire : Nissan Leaf 2016-2018, architecture pour brancher n'importe quelle voiture par un profil.

**Documentation** : [`docs/`](docs/README.md) (organisation Diataxis : tutoriels, guides, référence, explication, gestion).

Commencer par [`docs/explanation/FONCTIONNEMENT_CAN_OBD.md`](docs/explanation/FONCTIONNEMENT_CAN_OBD.md), puis [`docs/tutorials/PREMIER_ESSAI_ROUTIER.md`](docs/tutorials/PREMIER_ESSAI_ROUTIER.md). Le plan complet est dans [`docs/management/PLAN.md`](docs/management/PLAN.md).

> Dépôt destiné à rester privé (préférence de l'utilisateur ; à vérifier dans les réglages GitHub) : les journaux bruts et traces GPS ne sont pas versionnés (voir `docs/explanation/DONNEES_ET_VIE_PRIVEE.md`).
